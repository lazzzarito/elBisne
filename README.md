# Shopa

Proyecto en desarrollo. Este repositorio contiene la versión inicial del sitio Shopa.

Estado: En desarrollo — trabajo en progreso.

Qué hay aquí
- Archivos del sitio web para desplegar en Vercel.

Cómo desplegar (resumen rápido)
1. Crear un repositorio en GitHub e inicializar git localmente.
2. Subir (push) la rama principal al remoto.
3. Importar el repositorio en Vercel y desplegar (site estático).

Comandos sugeridos:
```bash
git init
git add .
git commit -m "Initial commit: Shopa site"
git remote add origin <URL_DE_TU_REPOSITORIO>
git push -u origin main
```

Asegurar el dominio
- En Vercel, en la sección de Dominios del proyecto, añade el dominio que deseas asegurar.
- Sigue las instrucciones para configurar los registros DNS (A / CNAME) en el proveedor de dominio.

Notas
- Si quieres ayuda para conectar GitHub o configurar el dominio en Vercel, dime y lo hago paso a paso.
